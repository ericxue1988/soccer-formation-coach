# Formation Coach

A lightweight interactive soccer formation coaching draft.

## Current Draft

- SVG tactics pitch
- Draggable players
- Formation presets: `4-3-3`, `4-2-3-1`, `3-5-2`
- Phase presets: base, possession, defense, pressing
- Play button for animated shape evolution
- Reset button
- Draw mode for tactical arrows
- Click a player for role requirements, skills, responsibilities, and mistakes to avoid
- Overview, details, and drills panels

## Run

From this folder:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173/
```

No npm install or build step is required for this first version.
